## 데이터 분석이란?

데이터를 **수집, 정리, 가공, 분석**하여 의미 있는 정보를 도출하는 과정이다.
단순히 데이터를 관찰하는 것이 아니라, 패턴을 찾고, 문제를 해결하며, 더 나은 **의사 결정을 지원**하는 데 목적이 있다.

![](images/data-analysis-정의.png)

- 소셜 미디어 사용 기록
- 온라인 쇼핑 내역
- 금융 거래 기록
- 센서 데이터, 위치 데이터

이러한 데이터를 분석하면 **고객 예측**, **매출 증대**, **비용 절감** 등의 효과를 얻을 수 있다.

## **데이터 사이언스와 데이터 분석**

데이터 사이언스는 **수학과 통계학, 컴퓨터 과학, 비즈니스 도메인 지식이 융합**된 분야이다. 이러한 다양한 영역의 지식을 바탕으로 데이터로부터 유의미한 인사이트를 도출하고 비즈니스 가치를 창출한다.
데이터분석과 데이터사이언스는 서로 밀접하게 연관되어 있지만, 데이터 사이언스가 더 광범위한 개념이다. 데이터 분석이 주로 데이터로부터 인사이트를 도출하는 데 중점을 둔다면, **데이터 사이언스는 여기에 더해 머신러닝, 인공지능, 고급 통계 기법 등을 활용하여 더 복잡한 문제를 해결**한다.

데이터 사이언스에 필요한 역량

- 호기심과 이론적 지식
- 분석 기술의 숙련
- 통찰력 있는 분석과 설득력 있는 전달
- 다분야간 협력

## 데이터 분석은 어디에 사용되는가?

데이터 분석은 산업 전반에 걸쳐 폭넓게 활용되고 있다.

| 분야 | 주요 활용 | 적용 사례 |
| --- | --- | --- |
| 마케팅 | 고객 세분화, 추천 시스템, 구매 패턴 분석, 타겟 마케팅, 광고 성과 예측 | 고객의 클릭 기록과 구매 이력을 분석하여 가장 구매 가능성이 높은 제품을 추천 |
| 금융 | 신용도 평가, 이상 거래 탐지, 리스크 관리, 주가 예측, 포트폴리오 최적화 | 고객의 거래 패턴을 분석해 카드 사기 탐지 모델 구축 |
| 제조 | 품질 관리, 공정 최적화, 설비 예지보전(PdM), 불량률 감소 및 생산 효율 향상 | 센서 데이터를 분석해 설비 고장을 사전에 감지 |
| 의료 | 진단 보조, 약물 효과 분석, 환자 예후 예측, 유전체 분석, 질병 조기 예측 | 영상 데이터를 분석해 암 조기 진단 모델 개발 |
| 유통·물류 | 수요 예측, 재고 최적화, 배송 경로 최적화, 고객 행동 분석을 통한 매장 진열 최적화 | - |

## 데이터 분석의 분류

데이터 분석은 목적과 방법에 따라 크게 네 가지로 나뉜다.

1. 기술 분석 (Descriptive Analytics) : **무슨 일이 일어났는가?**
    - 과거의 데이터를 요약하고 정리
    - 평균, 합계, 빈도수, 시각화 등
    - 매출 데이터 분석, 고객 수 변화 추이 확인
2. 진단 분석 (Diagnostic Analytics) : **왜 그런 일이 일어났는가?**
    - 변수 간 관계 파악
    - 원인 분석, 상관관계 탐색
    - 매출 하락 원인을 지역·제품·시간대별로 분해 분석
3. 예측 분석 (Predictive Analytics) : **앞으로 무슨 일이 일어날 것인가?**
    - 과거 데이터를 기반으로 미래 결과 예측
    - 머신러닝, 회귀분석, 시계열 분석 등
    - 고객 이탈 예측, 다음 달 매출 예측
4. 처방 분석 (Prescriptive Analytics) : **무엇을 해야 가장 좋을까?**
    - 최적의 의사결정을 위한 조언 제공
    - 시뮬레이션, 최적화 기법 활용
    - 가장 효과적인 마케팅 전략 추천, 재고 최적 주문 수량 제안

이 네 가지 분석은 순차적이거나 복합적으로 사용되며, **단순 보고에서 지능적 의사결정으로의 전환**을 가능하게 한다.

## 새로운 **의사결정**을 가능하게 하는 정보(가치)의 도출

정보의 유형

- **이미 알고 있는 것을 수치화한 것** → 객관화를 통해 합의 도출에 유용
- **생각해보지 않았던 사실** → 그러나 생각해 보면 알 수 있었던 것
- **궁금해도 알 수 없었던 사실** → 예: 내일의 날씨, 신제품의 판매량 예측 등

**공감대 형성이 가능한 질문**

![](images/data-analysis-process-focus.png)

### 데이터 전처리

데이터의 품질을 높이고 분석에 적합한 형태로 만드는 과정으로, 결측치 처리, 이상치 제거, 데이터 형식 변환 등의 작업을 포함한다. 전처리 과정은 분석 결과의 신뢰성을 좌우하는 매우 중요한 단계이다.

데이터 클린징과 데이터 전처리

| 구분 | 데이터 전처리 (Preprocessing) | 데이터 클렌징 (Cleansing) |
| --- | --- | --- |
| **정의** | 분석이나 모델링에 적합하도록 데이터를 구조화하고 가공하는 전체 과정 | 원천 데이터의 오류나 문제를 정제하여 **신뢰도**를 높이는 과정 |
| **목적** | 분석 가능하도록 **형식과 구조**를 준비하는 것 | **정확성**과 **일관성** 확보 |
| **주요 작업** | 타입 변환, 컬럼 생성, 스케일링, 범주형 인코딩, 요약 집계 | 결측치 처리, 이상치 제거, 중복 제거, 오류값 수정 |
| **관점** | 기능적인 준비 (모델/시각화 등 목적 중심) | 데이터의 질적 개선 (신뢰성 중심) |
| **결과** | 분석 가능한 상태의 **포맷팅된 데이터셋** | **깨끗하고 오류 없는 데이터셋** |
| **선후 관계** | 보통 **클렌징 후 전처리** 수행 | 클렌징은 전처리의 **선행 또는 병행 작업** |

### 데이터 분석

1. **기초 통계 분석** : 평균, 중앙값, 분산, 최빈값, 표준편차 등 요약 통계, 그룹별 요약 (`groupby`)
2. **상관 분석** : 변수 간 관계 파악
3. **추세 분석** : 시계열 데이터의 흐름 확인 : 월별 증가 추세, 주중과 주말 비교
4. **분류 및 그룹화** : 범주형 데이터 기준으로 세분화
5. **이상치 탐지** : 상자그림(Boxplot), Z-score, IQR 등을 통해 이상값 확인

### 시각화

1. **패턴 인식 시각화** : Line plot, bar chart, heatmap 등을 통해 **패턴과 추세**를 시각적으로 표현
2. **분포 확인** : 히스토그램, 커널 밀도 추정(KDE)
3. **비교 시각화** : 여러 변수 또는 집단 간 차이 비교
4. **상관관계 시각화** : Scatter plot, pairplot, heatmap 등
5. **스토리텔링용 대시보드 제작** : Plotly, Tableau, Power BI, Streamlit 등을 사용해 **인터랙티브한 시각화 구현**
